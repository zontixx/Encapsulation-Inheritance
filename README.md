# Java OOP Concepts: Encapsulation and Inheritance

This project is a simple Java-based demonstration of two fundamental Object-Oriented Programming (OOP) concepts: **Encapsulation** and **Inheritance**.

## 📚 Topics Covered

- **Encapsulation**: Using private fields with public getter and setter methods to protect data.
- **Inheritance**: Demonstrating how a subclass can inherit properties and methods from a superclass.

## 🧱 Project Structure

- `Person.java`: A base class containing common attributes like name, age, and methods (e.g., getters/setters).
- `Student.java`: A subclass that inherits from `Person` and may include additional fields such as `studentId`.
- `Teacher.java`: Another subclass that also inherits from `Person` and may include `subject` or similar properties.
- `Main.java`: The entry point of the application. It creates instances of `Student` and `Teacher` and demonstrates encapsulation and inheritance in action.
